# Lessons

## 2026-07-20 — Clarify round illustration scope

- Before designing a requested round illustration, clarify whether it should explain player-facing gameplay or generation internals.
- For generation reviews, trace the executable pipeline rather than inferring behavior from round names, instructions, or scoring.
- Distinguish initial generation from browser replacement paths, files read as sources from files used only as append destinations, and declared template difficulty from the selector's actual target.
